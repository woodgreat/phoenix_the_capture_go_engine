# Phoenix 编译指南 How to Build Phoenix

> 本文档介绍如何编译 Phoenix 引擎的 Linux 和 Windows 版本。
> This document describes how to build Phoenix engine for Linux and Windows.

---

## 📁 编译配置位置 Build Configuration Location

```
phoenix_hust/
├── configs/                          # ← 编译配置目录 Build configs
│   ├── config-linux.toml             # Linux 编译配置 Linux build config
│   └── config-windows.toml           # Windows 编译配置 Windows build config
├── build.sh                          # 编译脚本 Build script
└── dist/                             # 编译输出目录 Build output (not in git)
    ├── linux/
    ├── windows/
    └── temp/
```

## 🔧 环境要求 Prerequisites

### 系统要求 System Requirements

**操作系统 OS:** Linux（推荐 Ubuntu/Debian）
**注意 Note:** Windows 版本需要在 **安装了 MinGW 的 Linux 系统** 上交叉编译
**Note:** Windows version requires cross-compilation on **Linux with MinGW installed**

### 编译依赖 Build Dependencies

| 依赖 Dependency | 版本 Version | 用途 Purpose | 安装命令 Install Command |
|----------------|-------------|-------------|------------------------|
| **Rust 工具链** Rust toolchain | 1.70+ | 编译 Rust 代码 Compile Rust code | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |
| **Hust 编译器** Hust compiler | 0.3.11+ | 将 Hust 代码转译为 Rust Transpile Hust to Rust | 见 Hust 文档 see Hust docs |
| **MinGW-w64** MinGW-w64 | 最新 Latest | Windows 交叉编译链接器 Windows cross-compilation linker | `sudo apt-get install mingw-w64` |
| **GCC** GCC | 最新 Latest | Linux 链接器 Linux linker | `sudo apt-get install build-essential` |

**推荐版本 Recommended Version:** Rust 1.70 或更高版本 Rust 1.70 or higher

### Linux 编译 Build for Linux

| 要求 Requirement | 状态 Status | 安装命令 Install Command |

### Windows 编译 Build for Windows

| 要求 Requirement | 状态 Status | 安装命令 Install Command |

## 🚀 快速开始 Quick Start

### 方法 1：使用编译脚本（推荐）Method 1: Using Build Script (Recommended)

```bash
cd /home/aaa/workspace/phoenix_the_capture_go_engine/phoenix_the_capture_go_engine/phoenix_hust

# 编译 Linux 版本 Build Linux version
./build.sh linux

# 编译 Windows 版本 Build Windows version
./build.sh windows

# 编译所有平台 Build all platforms
./build.sh all
```

**脚本自动完成：What the script does automatically:**
1. 调用 `hust build .` 生成 Rust 代码 Generate Rust code from Hust
2. 复制对应的配置文件到 Cargo 项目 Copy config to Cargo project
3. 用 `cargo build` 编译 Compile with Cargo
4. 把产物复制到 `dist/` 目录 Copy output to `dist/`

---

### 方法 2：手动编译（高级）Method 2: Manual Build (Advanced)

```bash
# Step 1: Hust 编译生成 Rust 代码
# Step 1: Generate Rust code from Hust
hust build .

# Step 2: 找到 Hust 生成的 Cargo 项目
# Step 2: Find the Cargo project generated by Hust
HUST_TEMP=$(find /home/aaa/.cargo/bin/build -name "Cargo.toml" -type f | head -1 | xargs dirname)

# Step 3: 复制配置文件
# Step 3: Copy configuration file
mkdir -p "$HUST_TEMP/.cargo"
cp configs/config-windows.toml "$HUST_TEMP/.cargo/config.toml"

# Step 4: 编译
# Step 4: Compile
cd "$HUST_TEMP"
cargo build --release --target x86_64-pc-windows-gnu

# Step 5: 复制产物到 dist/
# Step 5: Copy output to dist/
cp target/x86_64-pc-windows-gnu/release/phoenix.exe /path/to/dist/windows/
```

## 📋 编译配置文件说明 Build Configuration Files

### Linux 配置 `configs/config-linux.toml`

```toml
# Linux 编译配置
# Linux build configuration
# 用法 Usage: cargo build --release --config configs/config-linux.toml

[build]
target = "x86_64-unknown-linux-gnu"

[target.x86_64-unknown-linux-gnu]
linker = "cc"
```

| 字段 Field | 说明 Description |
|-----------|-----------------|
| `build.target` | 目标平台 Target platform |
| `target.*.linker` | 链接器 Linker（Linux 使用系统默认 `cc`） |

---

### Windows 配置 `configs/config-windows.toml`

```toml
# Windows 交叉编译配置
# Windows cross-compilation configuration
# 用法 Usage: cargo build --release --config configs/config-windows.toml
# 注意 Note: 需要安装 MinGW 链接器 MinGW linker required

[build]
target = "x86_64-pc-windows-gnu"

[target.x86_64-pc-windows-gnu]
linker = "x86_64-w64-mingw32-gcc"
```

| 字段 Field | 说明 Description |
|-----------|-----------------|
| `build.target` | 目标平台 Target platform（Windows x86_64） |
| `target.*.linker` | 链接器 Linker（MinGW 的 `x86_64-w64-mingw32-gcc`） |

## ⚙️ 高级配置 Advanced Configuration

### 修改优化级别 Change Optimization Level

编辑对应的配置文件 Edit the corresponding config file:

```toml
[profile.release]
opt-level = 3          # 优化级别 0-3 Optimization level 0-3
lto = true             # 链接时优化 Link-time optimization
debug = false          # 是否包含调试信息 Include debug info
```

### 添加新平台 Add New Platform

1. 创建新配置文件 Create new config file:
   ```bash
   cp configs/config-linux.toml configs/config-macos.toml
   ```

2. 修改 target 和 linker Modify target and linker:
   ```toml
   [build]
   target = "x86_64-apple-darwin"
   
   [target.x86_64-apple-darwin]
   linker = "cc"
   ```

3. 安装对应 target Install corresponding target:
   ```bash
   rustup target add x86_64-apple-darwin
   ```

4. 更新 `build.sh` 脚本 Update `build.sh` script

## 🐛 故障排除 Troubleshooting

### Q1: 编译 Windows 版本时提示找不到链接器？
### Q1: Linker not found when building Windows version?

**错误 Error:** `linker "x86_64-w64-mingw32-gcc" not found`

**解决 Solution:**
```bash
# Ubuntu/Debian
sudo apt-get install mingw-w64

# CentOS/RHEL
sudo yum install mingw64-gcc

# Arch Linux
sudo pacman -S mingw-w64-gcc
```

---

### Q2: 如何清理编译缓存？
### Q2: How to clean build cache?

**Linux:**
```bash
rm -rf dist/temp/linux
```

**Windows:**
```bash
rm -rf dist/temp/windows
```

**全部清理 Clean all:**
```bash
rm -rf dist/temp/*
```

---

### Q3: 编译产物太大，如何减小体积？
### Q3: Build output too large, how to reduce size?

**方法 Method:** 在配置文件中启用 LTO 和 strip
**Method:** Enable LTO and strip in config file

```toml
[profile.release]
lto = true
codegen-units = 1
panic = "abort"
strip = true
```

---

### Q4: 如何交叉编译 32 位版本？
### Q4: How to cross-compile 32-bit version?

**Linux 32 位 Linux 32-bit:**
```toml
[build]
target = "i686-unknown-linux-gnu"
```

**Windows 32 位 Windows 32-bit:**
```toml
[build]
target = "i686-pc-windows-gnu"

[target.i686-pc-windows-gnu]
linker = "i686-w64-mingw32-gcc"
```

- **操作系统 OS:** Ubuntu 22.04 LTS (x86_64)

### 复现步骤 Reproduction Steps

**1. 安装依赖 Install Dependencies**
```bash
# 更新系统 Update system
sudo apt-get update
sudo apt-get upgrade -y

# 安装基础工具 Install basic tools
sudo apt-get install -y build-essential curl git

# 安装 MinGW Install MinGW
sudo apt-get install -y mingw-w64

# 安装 Rust Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

rustup target add x86_64-unknown-linux-gnu
```
